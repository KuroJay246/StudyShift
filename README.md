# StudyShift

An offline-first personal planner that brings work shifts, education, and everyday plans into one user-controlled schedule.

## Project status

Phase 1 Android implementation is active. The app now has Today, Week, Work, Study and More screens, schedule details, manual work/class entry, local SQLite/Drift persistence, DST validation, recurrence handling and a native Android widget. The owner-selected StudyShift navy/blue/cyan identity and timetable composition are recorded in `DESIGN.md`. See [the implementation roadmap](docs/ROADMAP.md) for build identity, verified evidence and remaining acceptance work.
