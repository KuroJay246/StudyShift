## Open gates

1. **Galaxy acceptance:** The Galaxy ADB transport is visible, but the owner said they are using the phone. No current-build phone acceptance was performed; resume when the phone is available, without editing the owner's existing roster.
2. **OCR privacy:** Google confirms ML Kit processes the image and recognized text on-device, but its Android SDK sends technical diagnostics and usage metrics. StudyShift requires a one-time, per-import disclosure and confirmation before opening an OCR picker; schedule content and recognition output are not sent. Confirm the final product disclosure/data-safety treatment against the project's no-telemetry-by-default policy. The offline alternative still needs a current, security-reviewed Android build and model review.
3. **Reference-data completeness:** Reusable shift-code reference data for code-to-time/flight selection still needs review against the provided roster before it can be called complete.
4. **Signing and update:** Release key custody remains owner-controlled. A signed APK and retained-data update test are not available until that gate is completed.
5. **Startup target:** Restored-data build `24421` previously produced an ANR and a later roughly **25-second** launch with **199 skipped frames**. Clean-emulator build `28436` cold starts measured **2.377–2.684 seconds**, but one 600 ms frame was recorded and the Perfetto trace has not been processed. Cold start with restored data and the three-second target on Galaxy remain unverified.
